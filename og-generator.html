How to use this file:
  1. Open this file in Chrome (File → Open, or drag into browser)
  2. For each card below, right-click the card → Inspect → find the .og-card div → right-click in DevTools → "Capture node screenshot". This exports exactly 1200×630px.
  3. Alternatively: use the browser zoom to make the card fill your screen, then screenshot and crop to 1200×630.
  4. Save as og/blog-10-features.png and og/blog-10-removals.png in your repo root.
The /og/ folder should sit at the root of your Vercel project alongside index.html.
